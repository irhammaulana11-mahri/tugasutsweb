## Deskripsi Proyek

BimbelCerdas merupakan rancangan website lembaga bimbingan belajar yang dibuat sebagai bagian dari tugas Ujian Tengah Semester (UTS) mata kuliah Pemrograman Antarmuka Web.

Website ini dirancang untuk memberikan informasi mengenai layanan bimbingan belajar, pilihan program pendidikan, biaya pendaftaran, profil pengajar, serta menyediakan formulir pendaftaran peserta didik secara online.

Dalam pengembangannya, website menggunakan HTML5 sebagai struktur halaman, CSS3 untuk pengaturan tampilan, JavaScript untuk interaksi antarmuka, serta Bootstrap 5.3 untuk membantu membangun desain yang responsif.

Website dibuat dengan memperhatikan kemudahan penggunaan, konsistensi desain, dan kompatibilitas tampilan pada perangkat desktop maupun mobile.
